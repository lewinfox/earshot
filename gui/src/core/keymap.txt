# earshot's keyboard. One binding per line:
#
#   <mode>  <key>  <command>  [<number>]
#
# mode     perform, prepare, controller, or any (all of them)
# key      a key's name: A, 1, ;, Left, Up, Space, Tab, Enter, … with Shift+ and/or
#          Ctrl+ in front for the shifted key (Ctrl is Cmd on a Mac). Keys go by where
#          they are on the keyboard, named as on a US layout. A shifted key with no
#          binding of its own does what it does unshifted.
# command  a command's name, from docs/commands.md: deck_1_play, mixer_crossfader,
#          fx_1_on, library_browse, … Here, target_ in place of deck_N_ means Prepare's
#          target deck (the one picked in its top bar).
# number   the command's value (how far to jump or browse, the loop's beats). size
#          (or -size, for back) is the deck's configured beat jump or loop size.
#
# The key help (the Keys button) is made from this file.
