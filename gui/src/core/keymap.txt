# earshot's keyboard. One binding per line:
#
#   <mode>  <key>  <target>  <control>  [<number>]
#
# mode     perform, prepare, or any (both)
# key      a key's name: A, 1, ;, Left, Up, Space, Tab, Enter, … with Shift+ and/or
#          Ctrl+ in front for the shifted key (Ctrl is Cmd on a Mac). Keys go by where they are on the keyboard, named as on
#          a US layout. A shifted key with no binding of its own does what it does
#          unshifted.
# target   deck1 … deck4, target (Prepare's target deck: the one picked in its top
#          bar), mixer, fx1 (the effect unit; fx2 and on if there are more), or
#          library
# control  a control's name (core/bus.rs). The number is its parameter (the hot cue
#          pad, the loop's beats, the grid nudge in ms) or the value it sends (how far
#          to browse).
#
# The key help (the Keys button) is made from this file.
